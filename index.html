Atualização do Apps Script para Colunas J (CLIENTE) e K (OBSERVAÇÃO)
Como atualizar na planilha do Google Drive:
1. Na sua planilha, vá em Extensões → Apps Script.
2. Substitua a leitura da AGENDA no doGet e o appendRow no doPost (seção CRIAR_AGENDAMENTO) pelos blocos abaixo:
// No doGet() -> Leitura da Agenda (Colunas A até K):
const dadosAgenda = abaAgenda.getDataRange().getValues();
const listaAgenda = [];
for (let i = 1; i < dadosAgenda.length; i++) {
  const r = dadosAgenda[i];
  if (!r[0]) continue;
  listaAgenda.push({
    protocolo: r[0],
    dataHoraExibicao: r[1] ? Utilities.formatDate(new Date(r[1]), "GMT-3", "dd/MM/yyyy HH:mm") : "",
    setorSolicitante: r[2] || "",
    setorExecutante: r[3] || "",
    servico: r[4] || "",
    tag: r[5] || "",
    equipamento: r[6] || "",
    tecnico: r[7] || "",
    status: r[8] || "AGENDADO",
    cliente: r[9] || "",          // Coluna J: CLIENTE
    observacao: r[10] || ""       // Coluna K: OBSERVAÇÃO
  });
}

// No doPost() -> CRIAR_AGENDAMENTO:
abaAgenda.appendRow([
  novoProtocolo,                  // Coluna A
  dataFormatada,                  // Coluna B
  dados.setorSolicitante || "",   // Coluna C
  dados.setorExecutante || "",    // Coluna D
  dados.servico || "",            // Coluna E
  dados.tag || "",                // Coluna F
  dados.equipamento || "",        // Coluna G
  dados.tecnico || "",            // Coluna H
  "AGENDADO",                     // Coluna I
  dados.cliente || "",            // Coluna J: CLIENTE
  dados.observacao || ""          // Coluna K: OBSERVAÇÃO
]);

Material de Apoio & Manual de Operação — DMA SYS v2.0

1. Agenda de Serviços & Calendário Mensal

Agende serviços integrados entre setores especificando o cliente e utilize o botão "Calendário Mensal" para visualizar a grelha do mês inteiro e validar conflitos de horário em tempo real.

2. Controle de Locação

Consulte saldos contratados vs. entregues por cliente e unidade hospitalar. Ajuste saldos físicos, valores e adicione notas de log diretamente pelo botão "Ajustar".

3. Módulo de Compras & Mapa Comparativo

Cadastre cotações informando 3 fornecedores. O sistema destaca a menor proposta em verde e registra a cotação com cálculo automático.

4. Módulo Qualidade & Termos

Acompanhe requisições internas, atenda com emissão do Termo Duplo de Entrega e Higienização ou vincule termos já emitidos pelo botão "Vincular".
